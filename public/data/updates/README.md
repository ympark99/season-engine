# 업데이트 (사이트 맨 앞 '업데이트' 탭)

정기 작업 두 개가 매일 실행을 끝낸 뒤 자기 파일에 그날 요약을 맨 앞에 넣는다. 사이트는 두 파일을 날짜별로 합쳐 한 화면에 보여준다 (미국·한국 구분 없이 한곳에).
파일마다 `days` 배열은 최신이 앞, 최근 30일만 남긴다. 같은 날 다시 돌면 그날 항목을 새로 덮어쓴다.
본문에 증권사·애널리스트·데이터 제공처 이름은 쓰지 않는다. 종목은 `m`(US/KR)·`code`·`name` 을 넣는다 — 화면에서 누르면 상세로 간다.

## macro.json — '유닉스 서버 갱신' (매크로 · 매출 흐름도)
```json
{ "days": [ {
  "d": "2026-10-16", "at": "2026-10-16T07:40:00+09:00",
  "summary": "오늘 시장을 두세 문장으로 — 미국·한국 각각 무엇이 움직였나",
  "risk": { "US": -1, "KR": -2, "chg": "유지 · 또는 '한국 −1 → −2 (이유 한 줄)'" },
  "changes": [ "판단·감시 지표·범주 뷰 변화 한 줄씩 (세운·폐기한 판단, good/bad 로 바뀐 지표 등)" ],
  "news": [ { "m": "KR", "t": "바뀐 소식 제목 한 줄", "note": "왜 중요한지 한 줄" } ],
  "flows": [ { "m": "US", "code": "ADI", "name": "Analog Devices" } ]
} ] }
```
- `flows` = 그날 매출 흐름도를 새로 쓰거나 고친 종목 목록만 (요약 없이).

## intel.json — '경쟁·기술 갱신' (종목 조사)
```json
{ "days": [ {
  "d": "2026-10-16", "at": "2026-10-16T06:55:00+09:00",
  "summary": "오늘 조사 한두 줄 — 대상 수, 깊은 갱신 수, 눈에 띄는 변화",
  "news": [ { "m": "US", "code": "TSLA", "name": "Tesla", "note": "바뀐 소식 한 줄" } ],
  "checkpoints": [ { "m": "US", "code": "META", "name": "Meta", "what": "3분기 실적", "d": "2026-10-21", "from": "예정", "to": "예정", "note": "발표일 10/21 확정 (무엇이 바뀌었나 한 줄)" } ],
  "newIntel": [ { "m": "KR", "code": "475150", "name": "SK이터닉스" } ]
} ] }
```
- `news` = 깊은 갱신한 종목의 바뀐 소식, `checkpoints` = 상태·날짜가 바뀌었거나 새로 추가한 체크포인트(새로 추가면 `from` 은 null), `newIntel` = 처음 전체 조사한 종목 목록만.
